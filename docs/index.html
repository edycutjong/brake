L-03 How it works

One payment run, three days

Finance signs once. The agent only gets the powers it needs to stop a line, so a hijacked agent can delay a payment but cannot create one or change where it goes.

Mondaysign the run

Every line is signed twice, in one sitting

For each line, finance signs the payment (valid only from payday) and its matching cancellation. openRun binds the agent’s ERC-8004 identity, a stop budget and an expiry.

L-05 Questions a judge would ask

Before you score it

Q1Is this running on the live Aevum chain?+

Yes. Brake and its ERC-8004 registries are deployed on Aevum testnet 44005, and the hero, TOO LATE and stop-budget runs executed there with claude-sonnet-5-5; every hash is listed in DEMO.md and opens on the explorer. The live app is at app.brake.edycu.dev. Two things still use a local fork on purpose: the forge suite, pinned to one block so CI is reproducible, and the authorization-only signing run, which needs one more faucet claim.

Q2What happens if the agent itself is hijacked?+

It can delay a run: cancel up to maxStops lines (set per run by the payer) and hold lines. It cannot create a payment or change where one goes. Each stop is re-issuable, one payer allow releases a hold, and revokeAgent blocks Brake-routed stops at once.

Q3Anyone can submit the cancel. Isn’t that a hole?+

It is the mechanism: tUSD8 accepts a payer-signed cancel from any caller, which is what lets an agent with no funds stop a payment (G1, 7 fork tests). The stop budget binds only the Brake path, and the README says so: anyone holding a raw cancel signature can submit it to tUSD8 directly.

Q4What is mocked or simulated?+

Demo mode uses a labelled custodial testnet payer; scripts/sign_local.ts is the mode where your key signs. Seed emails are authored demo data, amounts are seed invoices × 0.0001 for the faucet, the vendor phone check in the re-issue step is simulated, and the model ran through a local CLI adapter (the SDK path was not measured).

Q5What if the payment already went through?+

Brake reports TOO LATE, charges no stop budget and opens a recovery ticket. It cannot claw funds back.

Q6Does prompt injection break it?+

The model has no pay tool and no signatures, rules can only stop, and no model output can turn a rule STOP into ALLOW. An injection can still suppress a stop that only the model would have made; the 25-email injection suite tracks that.
